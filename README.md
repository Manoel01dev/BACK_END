# API REST de Veículos

## 📚 AP1 - API REST com ASP.NET Core e .NET 10

Projeto desenvolvido para a atividade AP1 de desenvolvimento de uma API REST utilizando ASP.NET Core e .NET 10.

## 🚗 Tema

O tema escolhido para a API é **Veículos**.

A API permite cadastrar, consultar, atualizar e excluir veículos.

---

## 🎯 Objetivo

O objetivo deste projeto é desenvolver uma API REST simples utilizando:

- ASP.NET Core
- .NET 10
- Minimal API
- C#
- Records (DTOs)
- Lista em memória (`List<T>`)

A API implementa as operações básicas de CRUD:

- **Create** - cadastrar veículos
- **Read** - consultar veículos
- **Update** - atualizar veículos
- **Delete** - excluir veículos

Os dados são armazenados somente em memória durante a execução da aplicação.

---
